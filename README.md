# Rootwork

Rootwork is a simple HTML, CSS, and JavaScript app for social journaling, mood tracking, reflection, and community posting.

## Tech stack

- HTML
- CSS
- JavaScript


## Local setup

1. Clone the repository.
2. Open `index.html` directly in a browser, or serve the folder with a local static server.
3. Use the app as a front-end-only demo with browser `localStorage`.

## Notes

- This version is intentionally simple and clean.
- No backend, database, or dependency install is required.
- `localStorage` is used to store demo posts, letters, journal entries, and user state.
